# 第一版验证记录

验证环境：Linux，Python 3.12.14，Node.js 24.19.0。没有真实业务日志包，测试基于用户提供的两种日志文本、目录约定及生成的模拟包。

## 已执行并通过

命令：`python -m unittest discover -s tests -v`

13 项测试：

1. 用户提供的 access 格式、转义引号、线程、状态码和末列耗时。
2. 用户提供的 root 格式、19 位流水号原样保留、带时区时间解析。
3. 多 Node 嵌套 ZIP、GZIP 历史记录和完整来源路径。
4. Node / Pod / 类型 / 文件名 / 状态 / 耗时 AND 筛选、中文和连续文本匹配。
5. 精确流水号跨 Pod 追踪、Java 多行异常堆栈与文件上下文。
6. 同节点、时间范围、线程组合关联。
7. 160 条结果跨 4 页读取，无重复或遗漏，全量 NDJSON 导出相同记录。
8. 缺少 FTS 时扫描降级仍正确。
9. 按文件 ID 限定一个来源文件。
10. 损坏 GZIP 导入整体回滚，记录错误状态，不留下部分日志/索引。
11. GB18030 中文解码、ZIP 路径不写入宿主路径。
12. 真实本地 HTTP 上传、搜索和首页响应；跨 Origin / 非法 Host 拒绝；AI 缺少发送确认拒绝。
13. AI 模拟服务：接口检索优先错误请求，关联异常证据，构造兼容 chat completions 的请求。

另已执行：

- `python -m py_compile app.py demo.py`
- `node --check dist/app.js`
- 静态入口引用检查：HTML 引用 `/app.js` 和 `/style.css`，均由 HTTP 服务提供；无 CDN、网络字体或前端依赖。
